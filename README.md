This repository contains my Jupyter Notebook for the pirate intelligent agent from Project Two. This notebook shows how I applied reinforcement learning and neural network concepts to train an agent to navigate a treasure‑hunt environment. The goal of the project was to build a deep Q‑learning model that allowed the pirate to learn from experience, make better decisions over time, and eventually reach the treasure consistently.

For this project, I was given the starter environment, the game setup, and some helper functions that handled things like resetting the world, tracking rewards, and interacting with the grid. The parts I created myself included the Q‑training algorithm, the memory system for storing experiences, the neural network model, and the training loop that updated the agent’s behavior. I also wrote the logic that allowed the pirate to choose actions using an epsilon‑greedy strategy and learn from past states, actions, and rewards.

Throughout this course, I learned how reinforcement learning fits into the larger field of computer science. Computer scientists solve problems by breaking them down into smaller pieces, experimenting, and improving solutions over time. Reinforcement learning is a good example of this because the agent learns through trial and error, just like how we approach complex problems in real life. This project helped me understand how algorithms can adapt based on feedback and how neural networks can approximate decision‑making in uncertain environments.

Working on this project also made me think about the responsibilities computer scientists have. When building intelligent systems, it’s important to consider how the system affects the end user and the organization. Models need to be reliable, fair, and safe. Even though this project was a simple game environment, the same ideas apply to real‑world systems. If an AI makes decisions that impact people, we have to make sure the system behaves ethically and doesn’t cause harm.

Overall, this project helped me grow as a developer. It pushed me to understand how reinforcement learning works behind the scenes and how to structure a training loop that actually improves an agent’s performance. Adding this notebook to my portfolio shows that I can work with neural networks, implement Q‑learning, and apply machine learning concepts to solve problems. It also gives future employers a look at how I think through challenges and build working solutions.
